Detalhes dos Problemas e Soluções

🔒 SEC-01: Senha de Admin Exposta

O código importa a senha do admin através das variáveis de ambiente com prefixo VITE_. No Vite, variáveis com este prefixo são processadas em tempo de compilação e injetadas de forma literal no bundle público do JavaScript client-side. Qualquer usuário pode abrir as ferramentas do desenvolvedor, procurar por admin123 ou VITE_ADMIN_PASSWORD e encontrar a senha em texto claro.

// Código Atual (Exposto publicamente no browser) export const adminPassword = import.meta.env.VITE_ADMIN_PASSWORD || 'admin123'; if (typedPassword === adminPassword) { sessionStorage.setItem('audiogift_admin_auth', 'true'); } // Recomendação Segura (Autenticação no Servidor) // Utilize Supabase Auth na tela de login administrativo: const { data, error } = await supabase.auth.signInWithPassword({ email: adminEmail, password: adminPassword });

🗄️ SEC-02: Supabase RLS Inseguro

As políticas de banco de dados definidas em supabase_schema.sql usam a instrução using (true) tanto para a leitura quanto para a atualização. Isso significa que, conhecendo a URL do Supabase e a Anon Key (que obrigatoriamente ficam expostas no front-end), qualquer usuário da internet pode baixar a tabela completa de pedidos de forma anônima ou editar pedidos (ex. marcar status como pago ou alterar dados confidenciais de outros clientes).

-- Política Atual (Insegura) create policy "Permitir leitura pública por ID" on public.orders for select using (true); -- Libera tudo! -- Recomendação Segura (Uso de Anonymous Auth + user_id) -- Adicione a coluna `user_id` vinculada ao auth.uid() do Supabase. alter table public.orders add column user_id uuid default auth.uid(); create policy "Permitir leitura individual" on public.orders for select using (auth.uid() = user_id); -- Apenas o dono lê

⚡ PERF-01: Pacote Monolítico

Atualmente, main.js consolida todo o código de renderização do Quiz, a barra de carregamento, o sistema de checkout de pagamento por cartão/PIX, o preloader de homenagem, bem como toda a interface administrativa e manipulação de exportação CSV. Como resultado, o tamanho do arquivo inicial atinge mais de 229 KB, sobrecarregando navegadores móveis sob redes móveis lentas (3G/4G).

// Solução: Separação de Rotas e Dynamic Imports // No roteador principal em main.js: const renderRoute = async () => { const hash = window.location.hash; if (hash.startsWith('#admin')) { // Importa o dashboard do admin dinamicamente apenas quando acessado const { renderAdmin } = await import('./adminDashboard.js'); renderAdmin(app); } else { renderLandingPage(app); } };

🎥 PERF-04: Video Player Vimeo

A barra de anúncios no topo do site carrega players baseados em iframe incorporados diretamente do Vimeo. O carregamento de players externos síncronos desencadeia o download de múltiplos assets adicionais de rede do Vimeo (analytics, player control stylesheets, tracking SDKs), retardando substancialmente o início do carregamento de imagens essenciais, como a do Hero banner.

<!-- Iframe Vimeo Pesado --> <iframe src="https://player.vimeo.com/video/119522..." ...> <!-- Solução Ultra Leve (Hospedagem Direta) --> <video autoplay loop muted playsinline class="video-desktop"> <source src="/videos/campanha-desktop.mp4" type="video/mp4"> </video>

Plano de Ação Recomendado

1. Configurar Row Level Security (RLS) no Supabase

Substituir as diretivas permissivas de using (true) por verificações baseadas em ID de usuário (auth.uid() = user_id) para proteger a privacidade dos dados dos clientes.

2. Migrar Autenticação do Admin para o Supabase Auth

Remover a validação de string de texto exposta no frontend VITE_ADMIN_PASSWORD. Configurar um login administrativo seguro com email e senha gerenciados pelo Supabase.

3. Divisão de Código (Code-Splitting) no Vite

Refatorar o arquivo src/main.js para que a lógica e templates HTML do painel de administração fiquem em um arquivo separado, carregado sob demanda via dynamic imports.

4. Substituir Vídeo Vimeo por Tag Video Nativa

Fazer o download dos vídeos de campanha curta e hospedá-los diretamente em formato MP4 compactado, reduzindo em cerca de 400ms o tempo de carregamento da página acima da dobra.

5. Bundling dos Ícones Lucide

Substituir a biblioteca Lucide carregada síncrona por CDN por importações estáticas via NPM para que apenas os SVGs utilizados no site final sejam compilados pelo Vite.
